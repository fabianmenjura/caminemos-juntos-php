📝 ÚNICO PASO NECESARIO

EJECUTA ESTE SQL (30 segundos):
────────────────────────────────

1. Abre phpMyAdmin o HeidiSQL

2. Selecciona la base de datos: caminemos_juntos

3. Pega y ejecuta:

   ALTER TABLE seccion_acerca_de 
   ADD COLUMN IF NOT EXISTS imagen_principal VARCHAR(255) DEFAULT NULL 
   COMMENT 'Ruta de la imagen principal de la sección' 
   AFTER contenido;

   INSERT INTO seccion_acerca_de (clave, contenido)
   VALUES ('imagen_principal', 'assets/images/about-section.jpg')
   ON DUPLICATE KEY UPDATE contenido = contenido;

4. ¡Listo!

================================================================================
🎨 CAMBIAR LA IMAGEN (desde panel admin)
================================================================================

1. Ve a: http://localhost/caminemos-juntos-php/admin/acerca-de.html

2. Login si es necesario

3. En "Contenido Principal" verás "Imagen Principal"

4. Haz clic en "Seleccionar archivo"

5. Elige tu imagen (máx 2MB, JPG/PNG/WEBP)

6. La vista previa se muestra automáticamente

7. Haz clic en "Guardar Contenido"

8. ¡Actualiza el sitio y verás tu nueva imagen!

================================================================================
💡 TIPS PARA LA MEJOR IMAGEN
================================================================================

✓ Dimensiones: 800x600px (horizontal)
✓ Tamaño: Menos de 500KB
✓ Contenido: Adultos mayores felices, voluntarios ayudando
✓ Iluminación: Natural y cálida
✓ Evitar: Fotos oscuras, tristes o genéricas

OPTIMIZAR EN:
→ TinyPNG.com (reducir tamaño)
→ Squoosh.app (convertir a WEBP)

================================================================================
❓ PROBLEMAS?
================================================================================

NO VEO LA IMAGEN:
  - Ctrl + F5 para limpiar caché
  - Verifica que ejecutaste el SQL
  - Confirma que existe: assets/images/about-section.jpg

EL DISEÑO SE VE MAL:
  - Ctrl + F5 para limpiar caché
  - Abre consola del navegador (F12) para ver errores

NO PUEDO SUBIR IMAGEN:
  - Verifica tamaño < 2MB
  - Verifica formato: JPG, PNG, WEBP
  - Revisa permisos de assets/images/
