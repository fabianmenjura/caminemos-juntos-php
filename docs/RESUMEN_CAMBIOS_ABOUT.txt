PASO 1: Base de Datos (30 segundos)
────────────────────────────────────
Ejecuta: database/add-imagen-acerca-de.sql

En phpMyAdmin o HeidiSQL:
ALTER TABLE seccion_acerca_de 
ADD COLUMN IF NOT EXISTS imagen_principal VARCHAR(255) DEFAULT NULL;

INSERT INTO seccion_acerca_de (clave, contenido)
VALUES ('imagen_principal', 'assets/images/about-section.jpg')
ON DUPLICATE KEY UPDATE contenido = contenido;

PASO 2: Imagen Inicial (2 minutos)
────────────────────────────────────

================================================================================
🐛 SOLUCIÓN DE PROBLEMAS
================================================================================

PROBLEMA: No veo la imagen en el sitio
SOLUCIÓN:
  1. Verifica que el SQL se ejecutó: SELECT * FROM seccion_acerca_de;
  2. Confirma que existe: assets/images/about-section.jpg
  3. Revisa permisos: chmod 644 assets/images/about-section.jpg

PROBLEMA: No puedo subir desde el admin
SOLUCIÓN:
  1. Verifica tamaño < 2MB
  2. Formato válido: JPG, PNG, WEBP
  3. Permisos carpeta: chmod 755 assets/images/
  4. Revisa consola del navegador (F12)

PROBLEMA: El diseño se ve mal
SOLUCIÓN:
  1. Limpia caché: Ctrl + F5 (Windows) / Cmd + Shift + R (Mac)
  2. Verifica que style.css se carga
  3. Abre consola (F12) para ver errores CSS/JS
