✅ FLUJO DE TRABAJO
═══════════════════════════════════════════════════════════════════════

VOLUNTARIOS:
  1. Usuario llena formulario en el sitio público
  2. Se envía a /api/voluntarios
  3. Queda registrado con estado "nuevo"
  4. Admin ve la solicitud en el panel
  5. Admin puede aprobar, rechazar o revisar
  6. Se puede eliminar si es necesario

TESTIMONIOS:
  1. Usuario da clic en "Comparte tu Experiencia"
  2. Llena modal con nombre, rol, calificación y testimonio
  3. Se envía a /api/testimonios
  4. Queda como "pendiente de aprobación"
  5. Admin revisa en panel de testimonios
  6. Admin aprueba el testimonio
  7. (Opcional) Admin lo marca como "destacado"
  8. El testimonio aparece en la página principal

PATROCINADORES:
  - Por ahora muestra logos de ejemplo
  - Fácilmente expandible para conectar a BD

2. Scroll hacia abajo hasta "Testimonios"

   ✓ Botón "Comparte tu Experiencia"

   ✓ Clic en el botón

   ✓ Verificar mensaje de éxito

4. Scroll a "Únete a Nuestro Equipo"
   ✓ Ver formulario de voluntarios
   ✓ Llenar datos
   ✓ Seleccionar tipo (voluntario/tallerista/ambos)
   ✓ Enviar

5. Ir al admin panel:
   ✓ Login con admin/Admin123!

   ✓ Entrar a Voluntarios → ver el registro enviado
   ✓ Entrar a Testimonios → ver el testimonio (pendiente)

   ✓ Destacarlo (opcional)
